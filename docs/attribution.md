# Attribution and source boundaries

Reval is independently authored. No endorsement or affiliation is implied.

| Source | Influence | Reuse |
| --- | --- | --- |
| [evals-skills](https://github.com/ai-evals-course/evals-skills) | Routing, product-specific audit, human failure review, evaluator calibration | Conceptual influence; no source files copied |
| [ASPIRE paper](https://arxiv.org/html/2607.00272v1) and [project](https://research.nvidia.com/labs/gear/aspire/) | Detailed trace evidence and preserving reusable failure knowledge | Conceptual influence; no prompts, code, figures, or media copied |
| [Robium](https://github.com/robium-ai/robium) | Robotics-specific testing and tool-aware guidance | Conceptual influence; no source files copied |
| [Agent Skills CLI](https://github.com/vercel-labs/skills) | Distribution and installation | External installer; not vendored |

Sources were consulted during development in September 2026. Reval's skills,
fixtures, helper scripts, diagrams, and documentation are original contributions.
The standard Apache-2.0 license text is distributed as the project's license.

A paper's availability does not imply that every associated code or media artifact
shares its license. Before copying external material in a future change, inspect
the exact artifact's license, preserve attribution/notices, and record provenance.
The present repository avoids relying on an inferred upstream reuse license.

ASPIRE studies robot-program improvement. Reval's proposed evaluation study
measures the quality of coding agents' robotics evaluation work.
